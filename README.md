# SEOlity knowledge base

Private SEO knowledge for SEOlity (https://benlifood.ir/).

- `seolity/knowledge/fa`, `seolity/knowledge/en`: bundled best practices.
- `seolity/knowledge/notes`: notes you add in SEOlity.
- `seolity/knowledge/distilled`: written weekly by the **SEOlity knowledge builder** workflow (needs the repository secret `ANTHROPIC_API_KEY`).
- `seolity/knowledge/learned`: measured learnings from your SEO experiments.
